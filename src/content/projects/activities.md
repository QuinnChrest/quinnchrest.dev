Every bike ride and walk I've recorded on Strava on one glowing map, where the roads I travel most shine the brightest, plus a highlights page with totals, records and a year calendar. An import script turns my Strava export into a single JSON file and strips out anything near home before it's published. Built with help from Claude Code.
