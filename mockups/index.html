quinnchrest.dev redesign

Seven directions, all built with your real projects and dev log. Open each one, and resize the window to see the phone layout.

A · Editorial

Warm paper background with serif headlines, like a magazine. One long page: hero, three featured projects with photos, a numbered list for the rest, then the dev log as a journal. Follows your system's light or dark setting.

B · Terminal

The site as a code editor and shell. A file tree for navigation, ls for projects, git log for the dev log, gh api for stats. Dark only, monospace, retro-green. The most "developer" of the three.

C · Bento

A modern grid of rounded tiles: big intro, image tiles for the featured projects, small stat tiles, latest dev log entry and the rest of your projects. Has a light/dark toggle.

D · Swiss poster

Huge bold uppercase type, black rules and one yellow highlight. Projects are giant rows; hover one on desktop and its picture pops up beside it. Loud and confident.

E · Desktop

The site is a pastel computer desktop. Icons open project windows you can drag around, the dev log is a sticky-note window, and there's a dock. On a phone it turns into a home screen of app icons. The most playful one.

F · Topo trail

Outdoorsy: a topographic-map background, featured projects as "trailheads", the dev log as a dashed trail with stops, and stats as an elevation profile. Ties in your bike rides and photos. Follows light or dark.

G · Scrapbook

Hand-made and friendly: notebook paper, taped-on polaroids for projects, sticky notes for the dev log, handwriting and a red circle scribble. Light only for now.

Coming with any direction:

  • Each dev log entry gets its own page (for example /log/meet-hey-leo) so you can link to it, and it shows up better in search.
  • Each project can get its own page too, built from the same Markdown files.
  • Normal scrolling and real links in place of the sideways sliding sections.
  • Same setup as now: SvelteKit built as a static site, deployed to GitHub Pages, all content as Markdown in the repo, RSS and sitemap kept.

The stat numbers in the mock-ups are placeholders. The real site keeps pulling live numbers from GitHub.
